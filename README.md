# 课小帮 — 一对一家教智能备课与学情闭环系统

面向大学生家教场景的「备课 → 授课 → 学情记录 → 家校反馈」全流程工具。
队伍：备课汪汪队 ｜ 赛道：教育教学

## 目录结构

```
kexiaobang/
├─ app/                     一期 Web/H5 原型（自包含，可直接云端部署）
│  ├─ index.html
│  ├─ assets/css/           业务定制样式
│  ├─ assets/js/            页面逻辑（备课生成、学情记录、反馈生成）
│  ├─ assets/vendor/        第三方组件（WeUI，本地引入）
│  └─ data/
│     ├─ knowledge/         学科知识点树（核心技术资产）
│     └─ samples/           预置演示数据（学生档案、历史学情）
├─ docs/                    申报材料、设计文档、答辩稿
├─ tools/                   打包脚本（生成单文件版）
├─ prototypes/              原型图、界面截图、演示录屏
├─ 课小帮-单文件版.html       可直接双击运行的完整演示（由 tools 脚本生成）
└─ .gitignore
```

`app/` 目录自包含所有前端与数据文件，部署时直接整体上传即可。

## 技术栈

- 前端：原生 HTML + CSS + JavaScript，无框架、无构建步骤
- UI 组件：WeUI 2.6.26（Tencent，MIT 协议），本地引入，见 `app/assets/vendor/README.md`
- 生成引擎：知识点体系 + 题库 + 规则模板（可替换为大模型调用）
- 存储：浏览器 localStorage（二期替换为云数据库）

选用原生方案的原因：零依赖、双击即可运行、部署只需上传文件夹；同时 UI 沿用微信官方视觉规范，二期迁移小程序时界面无需重新设计。

## 技术路线

- **一期（已完成）**：Web/H5 端，云端部署出公网链接，验证备课—授课—反馈闭环。数据先用浏览器本地存储。
- **二期（规划）**：迁移微信小程序端；接入云数据库实现多端同步；补充微信登录与消息推送。
- **架构原则**：前端可替换，AI 能力层与数据层独立于前端，保证多端复用。

## 模块

| 模块 | 说明 |
| --- | --- |
| 智能备课 | 输入学生情况与知识点，生成讲练素材包，支持编辑换题 |
| 课堂互动辅助 | 预设互动模板 + AI 填充本课题目（二期扩展） |
| 课堂互动小游戏 | 「闯关夺星」按难度分三关，「错题复仇」用历史错题做 Boss；判定结果自动填入课堂记录，玩游戏即完成记录 |
| 学情记录与分析 | 课后快捷勾选题目掌握情况，自动生成学情分析与薄弱点 |
| 家校沟通 | 一键生成家长反馈话术与学情报告 |
| 学生工作台 | 学生身份登录：课堂互动（自评练习）、课后记录、作业任务；作业由课上「半会/不会」的题自动生成 |

## 运行

三种方式任选：

1. **单文件版（最省事）**：直接双击根目录的 `课小帮-单文件版.html`。全部样式、脚本、知识点与题库已内联，**单个文件、离线可用**，可直接微信发送给老师或评委。
2. **多文件版**：用任意静态服务器托管 `app/` 目录（如 `python -m http.server`），适合开发调试。
3. **重新生成单文件版**：改完 `app/` 里的任何文件后执行 `node tools/build-standalone.js`，会重新打包出根目录的单文件版。

## 部署到 GitHub Pages（获得公网链接）

仓库里已备好配置，推送后只需三步：

1. 打开仓库 **Settings → Pages**
2. **Source** 选择 **GitHub Actions**（不要选 Deploy from a branch）
3. 推送到 `master` 或 `main` 后，Actions 会自动构建并发布

约 1 分钟后访问 `https://<你的用户名>.github.io/<仓库名>/` 即可。

- 工作流文件：`.github/workflows/pages.yml`，仅发布 `app/` 目录（不包含 docs、tools）
- 若你改用「Deploy from a branch → root」，根目录的 `index.html` 会自动跳转到 `app/index.html`
- 注意：免费账号的 Pages **仅对公开仓库生效**；私有仓库需 GitHub Pro

## 演示路径

学生档案（选陈小雨）→ 智能备课（勾知识点 → 生成备课包）→ 课堂记录（逐题勾掌握/半会/不会）→ 保存并生成反馈 → 课后反馈（切换三种话术语气）

勾选结果会回写学情档案，下次备课时推荐内容随之变��，闭环可现场验证。

**学生端演示**：登录页「我是学生」处点「陈小雨」→ 课堂互动（自评闯关 / 错题复仇）→ 课后记录（看历史课次与老师备注）→ 作业任务（本次作业打勾）。作业完成状态只存在本机，不写回学情档案——正式成绩只由老师课堂判定产生。
